# First Tab - Examples by Workbook Type

The first substantive visible tab answers four questions. A document-control cover may precede it. **Nothing else is mandatory.**

1. **Purpose** - what is this, and what is in and out of scope?
2. **Result** - the answer, in a table.
3. **Basis or qualification** - anything that changes how the result should be read.
4. **Action** - what is required next, and from whom.

Use the sections that workbook needs. A rate build-up may answer all four in fifteen lines. A contested claim assessment may need seven blocks. Both are correct.

---

## Interim payment certificate

| | |
|---|---|
| Purpose | Certificate number, period, contract |
| Result | This period, previously certified, cumulative, retention, deductions, **net due** |
| Basis | Anything withheld and why; anything certified on a provisional basis |
| Action | Payment terms; documents outstanding for the next application |

No comparison section, no scenario section, no bridge. The reader wants the net figure and what was withheld.

## Forecast final cost

| | |
|---|---|
| Purpose | Period, scope covered, what a forecast is and is not |
| Result | Forecast by block - committed, assessed variations, provisional sums, estimated changes, risk allowance - **with the certainty of each block on its own row**, then the total |
| Basis | Movement since the last forecast and why; base-case assumptions labelled *"working forecast assumption only"* |
| Action | Decisions needed to firm up the soft blocks |

Combining statuses is correct here. Disclosing the composition is what makes it honest.

## Claim or variation assessment

| | |
|---|---|
| Purpose | What is claimed, what is assessed, what is excluded |
| Result | Claimed against assessed, side by side |
| Basis | The bridge from their position to the assessment, in stages; why any difference is not like-for-like |
| Action | Determinations required, documents awaited, owner against each |

The fullest case. Add a "measured or estimated" block only if part of the assessment is estimated.

## Rate build-up

| | |
|---|---|
| Purpose | The item, the source specification |
| Result | The rate, and its components |
| Basis | Which components are priced from quotations, which are assessed, which are unestablished |
| Action | Quotations outstanding |

Usually fifteen lines on one tab. A seven-section narrative would make it worse.

## Comparison sheet

| | |
|---|---|
| Purpose | What is being compared, on what basis |
| Result | The comparison, with the difference column |
| Basis | Anything not compared like-for-like |
| Action | Clarifications required from the tendering parties |

## Writing rules

**Fewest words that carry the point.** *"Assessed amount: SAR 284,236.92, excluding VAT"* is complete at six words. There is no minimum. Treat 70 words in one block as a signal to check whether it is doing two jobs, not as a limit.

**One idea per block.** If it needs a semicolon and an "although", split it.

**State, do not hedge.** Ask of every sentence: does this tell the reader something, or does it protect the writer?

> **Rejected on D-18:** "There are two separate groups of retaining walls, assessed on different bases. They are kept apart throughout and should not be added together without reading the note under each."
>
> The reader's response: *"my summary is not understandable, like I'm talking to myself."* "Assessed on different bases" carries no information, and warning someone not to add two numbers is not the same as telling them what the numbers are.

> **Accepted:** "This workbook covers two groups of retaining walls that sit at completely different stages. One is built scope under a live Contractor claim. The other is possible future work for which nothing has yet been designed."
>
> The reader now knows not to combine them, because they understand what each one is.

**Split any difference that is not like-for-like.** The D-18 bridge originally read "the two sides agree within about 2%". True in total, misleading in substance - 29.29 of the 35.43 m3 sat on the one wall with no shop drawing, compared against an assumed section. The honest form states both parts.

**No internal codes carrying the meaning.** `RFP-021` beside "Temporary traffic signage" helps. `R2` standing alone in place of "whether the Contractor's approved-with-comments shop sections govern measurement" does not.

**No revision archaeology.** "The previously issued assessment", not "Rev 04".

**No author voice.** "Assessed", not "WTP measures" or "our measure".

**Every material headline figure, and every figure whose basis is not obvious, carries a source in words** - *"Calculation Engine row 49; total of RW-01, RW-02 and RW-04 on Contractor sections"*. Routine components in a clearly labelled table are traced through direct cell references - an IPC does not need a source sentence against retention, previous certified and cumulative certified.

## Acceptance test

Read the tab aloud, then answer without scrolling back:

1. What is this?
2. What is the answer?
3. What would change it?
4. What happens next, and who does it?

Any hesitation is a defect in the tab, not in the reader.
